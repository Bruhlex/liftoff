Liftoff decompiler for obfuscator.io's VM

Liftoff turns JavaScript protected with the Virtualization option of obfuscator.io back into readable JavaScript. Files without a VM are deobfuscated with webcrack instead. Everything runs in your browser; the file is never uploaded.

How it works

    
    
      
  1. Normalize the file with webcrack
        (string arrays, wrappers, formatting).
    2. 
      
  2. Locate the interpreter by its shape and infer the role of each array
        (operand stack, registers, bytecode).
    3. 
      
  3. Map every handler to an instruction with about 130 rules; an unknown
        handler is explained by running one dispatch step instead of guessing.
    4. 
      
  4. Load the bytecode with the build's own loader.
    5. 
      
  5. Lift the bytecode with a symbolic operand stack and put the recovered
        functions back where they were called.
    6. 
    

    
The page reports how much of the bytecode came back as real code. An instruction counts as
      not recovered when its opcode could not be identified, when it had to be emitted as a
      placeholder call such as __UNKNOWN_12(...), or when a jump could not be
      structured. A file without an obfuscator.io virtual machine is passed through webcrack
      only.

    
Liftoff was written for the bachelor thesis How to CAPTCHA: The Influence of AI,
      Obfuscation, and Browser Features to Bot Detection in the Web (Technical University
      of Munich, 2026), which describes how it works and how it was evaluated.


    
Supported versions

      dashboard:

    
    
      
  • the earlier code generator (July 2026);
    • 
      
  • versions 8.0.6 and 8.0.8, preset VM Low, alone and combined
        with string arrays, control-flow flattening, numbers to expressions, split strings,
        transform object keys, raw output and the Browser or Node target.
    • 
    


    
Limitations

    
    
      
  • The paid hardening options of the virtual machine (for example encoded jumps, stateful
        opcodes or a split dispatcher) are untested. Later versions may change the instruction
        set; unknown handlers are then reported instead of guessed, and the recovery figure
        drops below 100 %.
    • 
      
  • Large files (about 1 MB and more) take minutes in the browser; the command-line
        version is several times faster.
